Two lines explaining one everyday thing — a traffic jam — to a 10-year-old.
Line 1 pictures it as a school hallway at bell time, everyone squeezing
through one door. Line 2 says honestly what that analogy maps (the
bottleneck and the wait) and what it leaves out (drivers choose their own
roads and can turn back).

## How to run

```sh
node main.ts   # writes entry.txt to /output (or $MAKEFUN_OUTPUT_DIR)
```

`main.ts` uses only the Node standard library and writes the same 183
characters on every run.
